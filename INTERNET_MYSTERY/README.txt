INTERNET MYSTERY
================

Python compatibility:
- Python 2.7.12
- Flask version compatible with Python 2.7
- Frontend uses old-style JavaScript (ES5) where practical.

RUN:
1. Put the project in a folder named CASES.
2. Install a Flask version that supports Python 2.7.
3. Run:
       python app.py
4. Open:
       http://127.0.0.1:5000

CASE 001 ASSETS:
Place these files manually:
static/apps/cases/case001/assets/images/office_0317.jpg
static/apps/cases/case001/assets/images/basement_blueprint.jpg
static/apps/cases/case001/assets/audio/REC_14-10-18_03.wav

IMPORTANT:
Do not put solution.json inside static/.
The browser never receives solution.json directly.
